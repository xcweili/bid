# MyTasks 页面 UI  redesign 设计说明

## 🎨 整体设计理念

### 设计原则
- **现代简洁**：采用现代化设计语言，去除冗余元素，突出核心内容
- **视觉层次**：通过色彩、间距、阴影建立清晰的视觉层次
- **交互流畅**：平滑的动画过渡，自然的悬停反馈
- **专业统一**：与 bid 项目整体风格保持一致的配色和组件规范

## 🎯 组件设计细节

### 1. 页面头部横幅

**设计特点**：
- 渐变蓝色背景 (`#1e40af` → `#3b82f6`)
- 64x64px 图标容器，半透明白色背景 + 毛玻璃效果
- 白色文字，清晰的层次结构
- 右侧快捷按钮，半透明样式
- 装饰性光晕效果（伪元素）

**交互**：
- 无动画，静态展示

### 2. 统计卡片

**设计特点**：
- 圆角：16px
- 白色背景 + 柔和阴影
- 64x64px 渐变图标容器
- 悬停效果：
  - 向上位移 6px
  - 阴影加深
  - 图标缩放 + 旋转 5 度
  - 光晕效果显现

**配色**：
- 全部项目：蓝色渐变 (`#dbeafe` → `#bfdbfe`)
- 待细化：橙色渐变 (`#fef3c7` → `#fde68a`)
- 进行中：蓝色渐变 (`#dbeafe` → `#93c5fd`)
- 已完成：绿色渐变 (`#d1fae5` → `#a7f3d0`)

### 3. Tabs 导航

**设计特点**：
- 大尺寸标签，增加点击区域
- 激活状态：底部 3px 蓝色边框 + 浅蓝背景渐变
- 悬停状态：浅灰背景
- 图标 + 文字组合

**交互**：
- 平滑切换动画
- 无页面刷新

### 4. 项目表格

**表头设计**：
- 渐变灰背景 (`#f9fafb` → `#f3f4f6`)
- 大写文字 + 字间距 0.3px
- 16px 垂直内边距
- 2px 底部边框

**单元格设计**：

**项目名称列**：
```
┌────────────────────────────────┐
│ [📁] 项目名称                   │
│     子标题/包名称               │
└────────────────────────────────┘
```
- 40x40px 图标容器，蓝色渐变背景
- 双行文本：标题（粗体）+ 副标题（次要）

**分派团队列**：
```
┌────────────────────────────────┐
│ 👥 团队名称                     │
└────────────────────────────────┘
```
- 浅紫色背景标签
- 图标 + 文字组合

**进度列**：
```
┌────────────────────────────────┐
│ ████████░░░░░░░░░ 65%          │
└────────────────────────────────┘
```
- 自定义进度条（非 Ant Design 默认）
- 8px 高度，圆角胶囊形
- 渐变填充（蓝→浅蓝 或 绿→浅绿）
- 闪烁动画效果（shimmer）
- 右侧百分比数字

**状态列**：
```
┌────────────────────────────────┐
│ ⚡ 执行中                       │
└────────────────────────────────┘
```
- 透明边框标签
- 彩色背景（半透明）
- 彩色文字
- 图标 + 文字

**操作列**：
```
┌────────────────────────────────┐
│ [查看 →]                        │
└────────────────────────────────┘
```
- 蓝色渐变背景按钮
- 无边框
- 悬停：向上位移 + 阴影加深

### 5. 展开区域（子任务）

**设计特点**：
- 浅灰渐变背景 (`#f9fafb` → `#f3f4f6`)
- 顶部标题栏：

## 🎬 交互与动画

### 1. 卡片悬停动画
```css
animation: fadeIn 0.5s ease-out;
transform: translateY(-6px);
box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.1);
```

### 2. 进度条动画
```css
animation: shimmer 2s infinite;
/* 光泽扫过效果 */
```

### 3. 展开/收起动画
- 使用 Ant Design 内置动画
- 平滑的高度过渡

### 4. 按钮悬停
```css
transform: translateY(-2px);
box-shadow: 0 4px 12px rgba(59, 130, 246, 0.4);
```

### 5. 加载顺序动画
- 统计卡片：依次延迟出现（0.1s / 0.15s / 0.2s / 0.25s）
- 使用 `fadeIn` 动画

## 🎉 设计亮点

1. **渐变横幅头部**：提升视觉冲击力，建立品牌识别
2. **动态进度条**：带闪烁动画，增强视觉吸引力
3. **卡片光晕效果**：悬停时显现，增加互动感
4. **图标缩放旋转**：统计卡片悬停动画，生动有趣
5. **自定义展开按钮**：区别于默认样式，更加精致
6. **子任务摘要栏**：快速了解任务完成情况
7. **统一配色系统**：与项目整体风格完美融合
